# Senda de los convenios

Aplicación sencilla para que el obispado dé seguimiento al progreso de los hermanos en la senda de los convenios (basada en el manual *Mi senda de los convenios*): checklist de ordenanzas y experiencias, y notas con fecha.

Los datos se guardan solo en el navegador del dispositivo (localStorage); no se envían a ningún servidor. Use **Respaldo → Descargar respaldo** con regularidad.

Para instalarla en el teléfono: abra el enlace de GitHub Pages y elija *Agregar a pantalla de inicio* (Android: menú ⋮; iPhone: Compartir).
