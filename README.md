# Senda de los convenios · Barrio Bajo Boquete

Herramienta interna del obispado del Barrio Bajo Boquete para dar seguimiento al progreso de los miembros en la senda de los convenios (basada en el manual *Mi senda de los convenios*): checklist de ordenanzas y experiencias, y notas con fecha.

## Datos y privacidad
- La información puede revelar creencias religiosas y se trata como dato sensible conforme a la Ley 81 de 2019.
- Se guarda cifrada en Google Firebase (Cloud Firestore, servidores en EE. UU.). Solo pueden leerla o modificarla las cuentas de Google autorizadas en `firestore.rules`.
- Este repositorio contiene solo el código; no contiene datos de miembros. La configuración de `firebase-config.js` es pública por diseño y la clave de API está restringida a este sitio.
- Registre únicamente lo necesario para ministrar y no comparta la información fuera del obispado. Cualquier miembro puede pedir que se corrijan o eliminen sus datos.
- No sustituye los registros oficiales de la Iglesia.

## Uso
Abra https://alain507.github.io/senda-de-los-convenios/ y elija *Agregar a pantalla de inicio* (Android: menú ⋮; iPhone: Compartir). Entre con una cuenta de Google autorizada. Use **Respaldo → Descargar respaldo** con regularidad.
